4. DEPLOYING TO VERCEL
================================================================================
The project is 100% prepared for Vercel Serverless deployment:
  - Ephemeral & Read-Only Safe: Zero SQLite dependencies; pure Supabase Cloud.
  - Port 443 REST: PostgREST communicates over standard HTTPS without connection pool exhaustion.
  - Static Asset Routing: `vercel.json` maps static files directly to `/frontend/static/$1`.

To deploy:
  1. Install Vercel CLI:
     npm i -g vercel
  2. In `d:\yes`, run:
     vercel
  3. Set Environment Variables in Vercel Dashboard (or via CLI):
     SUPABASE_URL=https://your-project.supabase.co
     SUPABASE_KEY=your_supabase_secret_key_here
     SECRET_KEY=your-production-secret-key
  4. Deploy to Production:
     vercel --prod
